# Vendored test server certificate

`server-cn-only.crt` and `server-cn-only.key` are copied **byte for byte** from
the PostgreSQL 18.6 source tree, `src/test/ssl/ssl/`. The SSL-enabled block of
`src/interfaces/libpq/t/005_negotiate_encryption.pl` installs them as the
server's `server.crt` and `server.key` (`:137`-`:144`), and so does its port,
`../t_005_negotiate_encryption.rs`. They are test fixtures: a throwaway key
generated by upstream's `src/test/ssl/sslfiles.mk`, never trusted by anything.

## Provenance

Taken from the `postgres/postgres` repository at tag `REL_18_6`, commit
`724edf9bde9d356724ad384a2e196edc3c9f80f7` (the pristine tag, not the tree
vendored in pgrust — see ADR-0008). Each file's git blob id equals the tag's
(`git hash-object` against `git ls-files -s` at the tag).
