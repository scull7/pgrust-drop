# Vendored test server certificates

Every file here is copied **byte for byte** from the PostgreSQL 18.6 source
tree, `src/test/ssl/ssl/`. They are test fixtures: throwaway keys and
certificates generated by upstream's `src/test/ssl/sslfiles.mk`, never trusted
by anything.

- `server-cn-only.crt` and `server-cn-only.key`: the SSL-enabled block of
  `src/interfaces/libpq/t/005_negotiate_encryption.pl` installs them as the
  server's `server.crt` and `server.key` (`:137`-`:144`), and so does its port,
  `../t_005_negotiate_encryption.rs`.
- The `server-*.crt` certificates: the ones `src/test/ssl/t/001_ssltests.pl`
  switches the server to for its host-name rows (`:293`-`:554`). Its port,
  `../t_001_ssltests.rs`, reads the names out of them. No key is needed for
  that, so none is vendored.
