### Reference binaries

The PGDG apt repository is unreachable from this environment: the outbound proxy
answers `403` to `CONNECT apt.postgresql.org:443` (policy denial), so
`apt.postgresql.org.sh` added the source but `apt-get update` could not fetch its
index and `postgresql-18`/`postgresql-client-18` have no installation candidate.
`/usr/lib/postgresql/18/bin` does not exist. The only PostgreSQL client on the
box is Ubuntu's `psql` 16.13 at `/usr/bin/psql`, which is not the 18.6 reference
and must not be used as one.

Consequence: every byte-diff gate that needs a C reference binary prints
`SKIP (flagged, not silent)` and passes. No gate may be weakened or narrowed to
compensate (AGENTS.md, "Never weaken a gate to get green").
