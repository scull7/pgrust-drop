# Vendored `\help` text

`sql_help.c` and `sql_help.h` are what PostgreSQL 18.6's own generator,
`src/bin/psql/create_help.pl`, writes from the SQL reference pages
`doc/src/sgml/ref/*.sgml`. C psql compiles them in; `helpSQL()`
(`src/bin/psql/help.c:593`) prints from their `QL_HELP` table. PostgreSQL 18
no longer ships them in its release tarball (the build generates them), so
they are generated here, once, and vendored **byte for byte**. rpsql parses
them at run time (`crates/rpsql/src/sql_help.rs`); do not reformat or edit
them by hand.
